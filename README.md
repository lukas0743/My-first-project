# AZULA Natural Care

## Shopify theme

- `dist/azula-shopify-theme.zip` – ready to upload in Shopify Admin → Online Store → Themes → Add theme → Upload zip file
- `shopify-theme/` – theme source (Online Store 2.0: Liquid, JSON templates, sections, snippets)
- `shopify-setup/ANLEITUNG.md` – setup guide (products, metafields, pages, menus, blog)
- `shopify-setup/products.csv` – optional import for the three products; `shampoo.jpg` / `conditioner.jpg` – product photos

## Static site

The original static version (`index.html`, `shop.html`, product pages, `philosophy.html`, `ingredients.html`,
`magazine.html`, `search.html`, `account.html`, `cart.html`) is unchanged. Open `index.html` in a browser.
